# AISimplified Brand Guidelines (Lightweight)

## Brand Positioning
AISimplified is a scalable AI infrastructure layer for voice-first enterprise automation and developer-led agent systems.

## Voice and Tone
- Confident
- Clear
- Premium
- Future-ready

## Logo System
- Horizontal logo: `public/brand/logo-horizontal-dark.svg`, `public/brand/logo-horizontal-light.svg`
- Stacked logo: `public/brand/logo-stacked-dark.svg`, `public/brand/logo-stacked-light.svg`
- Icon/monogram: `public/brand/icon-monogram-dark.svg`, `public/brand/icon-monogram-light.svg`
- Favicon: `public/favicon.svg`

## Color Palette
- Primary Deep Indigo: `#273985` / `#3C63F3`
- Accent Teal: `#06B6D4`
- Neutrals: Slate scale (`#F8FAFC` to `#0F172A`)

## Typography
- Primary font: Inter
- Headings: bold, tight tracking
- Body: clear and readable with high contrast

## UI Principles
- Minimal, enterprise-trust visual language
- Strong whitespace and clear hierarchy
- Subtle motion only for clarity and focus
- Accessibility-first contrast and responsive layout
